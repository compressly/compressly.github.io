About the project

Compression should be useful, private, and clear.

Compressly is a free desktop app for making media easier to share without sending it to somebody else’s server.

Download 2.0View source
Why it exists

Local tools should not feel limited.

Many compression tools specialize in one media type, require uploads, impose file-size limits, or hide useful controls behind a subscription. Compressly supports images, videos, and audio in one local workflow with no arbitrary file-size ceiling.

The project started as an effort to build exactly that tool and improve it through deliberate iteration, testing, and direct feedback.

What version 2.0 changes

More capable without becoming harder to use.

Version 2.0 introduces a separate Smart Compression workspace for fidelity-focused decisions, while preserving the exact target-size workflow for situations with a hard limit.

Detailed View, retry reporting, completion dashboards, and sampled visual analysis make the outcome easier to understand instead of hiding the work behind one progress bar.

How it works

Built on proven local media tools.

Compressly is built with Electron. FFmpeg handles video and audio processing, while Sharp handles images. Smart visual comparisons use FFmpeg’s SSIM filter with bounded frame sampling.

Source media and compressed outputs stay on your machine. The app does not upload files for processing.

Open source

Free to use and open to inspect.

Compressly is released under the MIT License. You can inspect the source, report problems, review changes, and download every published version from GitHub.
